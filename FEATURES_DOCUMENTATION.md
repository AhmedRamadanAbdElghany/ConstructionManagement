It provides tools for managing projects, resources, finances, quality, safety, and client communications in a centralized system.\n\n### Key Benefits\n- **Centralized Management**: All project data in one place\n- **Real-time Tracking**: Monitor progress, costs, and resources in real-time\n- **Multi-tenant Architecture**: Support for multiple companies with role-based access\n- **Comprehensive Reporting**: Advanced analytics and customizable reports\n- **Mobile-Friendly**: Access from anywhere with responsive design\n- **Secure**: JWT-based authentication and granular permissions\n\n### User Roles\n- **SystemAdmin**: Full system access, manages companies and global settings\n- **CompanyAdmin**: Manages company settings, projects, and users\n- **CompanyUser**: Project-level access with specific permissions\n- **NormalUser**: Limited access for specific tasks\n\n---\n\n## 1.
